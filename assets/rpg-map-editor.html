先确定生图区域、地面边界与可走区；墙体、物件、开口和参考层按场景需要添加。

1. 实际生图区域

室内墙体参数（可选）。室外或无墙场景保持 0 即可。

区域坐标固定为 (0,0) 到宽×高；缩放视图不会改变它。

3. 比例与拼接参考层

新增模式：填写参数后可加入一个新的参考层。

相邻地图、角色只用于比较大小和拼接连接位置；可直接用鼠标拖动。角色参考尺寸可自行输入。若参考图盖住待绘制位置，请按住 Alt 再绘制。参考层不会出现在“导出PNG底座”里。

4. 绘制工具

修改已有内容：选择对应工具后拖动轮廓节点；物件和通路开口可拖动整体或四角缩放。点击后可用“删除选中内容”。

5. 导入与导出

JSON 会内嵌参考图，并保留轮廓、可走区、物件和通路开口的可编辑数据；图片越大，JSON 文件越大。
