# 几何底座与生图约束

## 按场景选择几何

先确认用户要求的视角：正交俯视、正交斜俯视、等距或其他形式。HTML 的多边形、矩形、参考层和源图尺寸可辅助多种 2D 场景；其中“四向墙体”算法只适用于轴对齐的正交斜俯视室内边界。不要把它用于树林、道路或等距地图。

- `map_outline`：需要明确地面外形时使用。室外全画布地形可不绘制轮廓。
- `walkable`：角色脚点允许移动的区域；若通路复杂，可在引擎中细化多个碰撞/导航区域。
- `objects`：可选的主要物件地面占地。占地宽度与深度不代表视觉高度。物件还需记录完整视觉范围 `visual_extent` 和落地点 `sort_anchor`。
- `doors`：通路开口标记；可用于门、桥口、街道出口等。它只是标记，不会自动切断碰撞。
- `wall_profile`、`wall_surfaces`、`wall_corners`：可选室内墙体参数及生成结果。默认全 0；使用前让地面轮廓闭合，再检查全部墙面与墙角都在画布内。
- `scale_references`：相邻地图或角色尺度参考，可以拖动，也可以手工设置宽高与坐标；不会进入生图底座 PNG。

编辑器导出 `<map-id>-map-base.json`、`<map-id>-map-base.png`，还可导出包含参考层的 `<map-id>-reference-layout.png`。JSON 内嵌所选参考图片；导出的底座 PNG 只包含几何标记，不包含参考图。重新导入 JSON 可继续编辑。

## 参考图分工

为每张图记录路径、对应区域、角色与优先级：

- `geometry`：外形、位置、比例、通路；通常以已确认的 HTML 底座为主。
- `style`：色板、线条、材质、光照和绘制密度。
- `object`：指定物件或表面的实际造型、结构、纹理和配色。
- `negative`：需避免的错误。

指定物件样式时，要对照图片中的可辨识细节。对于建筑场景，墙面和地面宜单独列约束；室外场景则改为道路、植被、水面、建筑立面等相关元素。几何约束和样式约束冲突时，不要悄悄折中。

## 生成与验收

提示词依次说明：硬几何、视角与投影、指定样式、可自由设计的部分、分层要求、禁止项。要求模型保持底座画布比例、通路和主要占地不变。生成结果需要逐项与底座叠加比对；不能因整体氛围接近就忽略门位、边界、地面接触或指定样式错误。

高分辨率地图可在合格完整母图上做带重叠的局部重绘。每块记录 `core_bounds` 和包含重叠的 `generation_bounds`，坐标统一使用最终画布坐标。接缝优先放在纹理简单处；墙角、门框、物件轮廓和光影转折由单块完整负责。合并后检查尺寸、线条、纹理、光照、接缝和外部 Alpha。需要扭曲或非等比缩放才能拼上时，应重生对应块。
